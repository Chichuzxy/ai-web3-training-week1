## 实验 1: AI 辅助智能合约审计流水线

### 实验目标
构建一条 "AI 生成审计报告 → 人工复核 → 修复建议" 的自动化流程

### 步骤
1. **输入准备**
   - 选择一段智能合约代码（可以是 TraceRecorder.sol 或社区合约）
   - 保存为 `artifacts/audit-target.sol`

2. **AI 审计**
   - 使用 LLM 分析合约安全
   - 要求输出结构化 JSON 格式报告
   - 包含: 漏洞等级、描述、修复建议、置信度

3. **人工复核**
   - 审查 AI 输出的每一项发现
   - 标记误报 / 漏报
   - 补充 AI 未发现的隐患

4. **修复实施**
   - 根据报告修复问题
   - 重新部署到测试网验证
   - 记录修复前后的 gas 变化

5. **输出归档**
   - 审计原始报告 (`artifacts/audit-report-<date>.json`)
   - 修复后合约地址
   - 对比分析文档

## 实验 2: 链上数据查询 + AI 可视化分析

### 实验目标
实现 "查询链上交易数据 → AI 分析趋势 → 输出可读报告"

### 步骤
1. **数据获取**
   - 用 etherscan API 或子图查询某钱包/合约的交易历史
   - 提取: 交易列表、gas 消耗趋势、交互频率

2. **AI 分析**
   - 将数据 feed 给 LLM
   - 要求生成: 持仓分析、活动模式总结、异常检测

3. **输出**
   - 分析报告 (`artifacts/analysis-<date>.md`)
   - 可选: 简单的图表 visualization

## 实验 3: Chainlink Oracle + AI 决策 Pipeline

### 实验目标
搭建 "链下 oracle → 链上价格 → AI 解读 → 触发操作" 的完整链路

### 步骤
1. **Oracle 数据上链**
   - 部署一个读取 Chainlink price feeder 的合约
   - 在 Remix/Hardhat 中测试

2. **AI 解读**
   - 定期拉取 on-chain 价格数据
   - AI 分析市场趋势
   - 输出买入/持有/卖出信号

3. **自动执行（测试网）**
   - 当信号满足条件时，触发合约函数调用
   - 全程保留日志
